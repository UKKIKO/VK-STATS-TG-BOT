VK-TG-STAT-BOT
Умный Telegram-бот для сбора и аналитики статистики сообществ ВКонтакте с встроенной веб-панелью данных.

Проект разработан в качестве учебной работы по Python и анализу данных, демонстрируя принципы модульной архитектуры, многопоточности и работы с реляционными базами данных (SQLite).

🚀 Возможности
Телеграм-бот: Получение статистики "на лету".
Быстрая статистика по последним постам.
Расчет коэффициента вовлеченности (ER) и поиск лучших постов.
Управление списком отслеживаемых групп (CRUD).
Фоновый сбор: Автоматический сбор данных по расписанию (без участия пользователя).
Веб-аналитика (Streamlit): Визуализация накопленной статистики, графики вовлеченности и динамика показателей.
Безопасность: Разделение секретов (токены), использование переменных окружения и .gitignore.
Архитектура: Многопоточность, использование Pandas для аналитики, логирование операций.

🛠 Tech Stack
Язык: Python 3.9+
Библиотеки:
pyTelegramBotAPI (Telebot) — работа с Telegram Bot API.
vk_api — работа с VK API.
pandas — обработка и анализ данных.
sqlite3 — хранение данных.
streamlit — веб-интерфейс аналитики.
python-dotenv — управление конфигурацией.
logging — ведение логов.

📦 Установка и запуск
1. Клонирование репозитория
git clone https://github.com/UKKIKO/VK-STATS-TG-BOT.gitcd VK-STATS-TG-BOT
2. Установка зависимостей
Убедитесь, что у вас установлен Python. Создайте виртуальное окружение и установите библиотеки:
python -m venv venv
- Для Windows:
venv\Scripts\activate
- Для Linux/Mac:
source venv/bin/activate
pip install -r requirements.txt

3. Настройка конфигурации

В корне проекта находится файл .env.example. Сделайте его копию с именем .env и заполните реальные данные:
cp .env.example .env

Откройте .env и впишите свои токены:
VK_ACCESS_TOKEN=ваш_токен_группы_ВК
TG_BOT_TOKEN=токен_вашего_телеграм_бота

4. Запуск компонентов
Проект состоит из трех независимых частей, которые можно запускать в разных терминалах:
- Запуск Telegram-бота:
cd Develop
python Bot_Dev.py
- Запуск Планировщика (Сбор данных в фоне):
cd Develop
python Scheduler.py
- Запуск Веб-панели (Streamlit):
cd Develop
streamlit run app.py

📱 Команды бота
| Команда | Описание |
| :--- | :--- |
| `/start` | Приветственное сообщение и вводная. |
| `/help` | Список доступных команд. |
| `/simple @domain` | Вывод статистики по последним постам. |
| `/complex @domain` | Расчет среднего ER и поиск лучшего поста. |
| `/add @domain category` | Добавить группу в отслеживание. Категории: IT, Мемы, Новости, Искусство. |
| `/delete @domain` | Удалить группу из отслеживания. |
| `/list [category]` | Показать список отслеживаемых групп (всех или по категории). |
| `/info @domain` | Показать подробную информацию о группе из базы. |

📂 Структура проекта
VK-STATS-TG-BOT/
├── Develop/               # Основная папка с кодом
│   ├── Bot_Dev.py         # Логика Telegram-бота (хэндлеры).

├── .env.example           # Шаблон секретов.
├── .gitignore             # Правила игнорирования файлов.
└── README.md              # Этот файл.
